# SmartPI Dashboard 0.3.4

First versioned release for installation through Home Assistant Marketplace as a custom **Integration** repository.

## Requirements and installation

- Home Assistant **2026.11.0 or newer**.
- A thermostat publishing **SmartPI Diagnostics v2**.
- Add `gael1980/smartpi-dashboard` in Marketplace as a custom Integration repository, install it, then add **SmartPI Dashboard** under Devices & services.
- For an existing installation, install the update and **restart Home Assistant**. Reload the panel afterward.
- The compiled frontend is included. No Node.js build or external token is needed on Home Assistant.
- The panel interface is in French; setup translations include French and English.
- This release does not add the repository to the default Marketplace catalog.

## What changes in 0.3.4

- Explains maintenance heating when the published signals show positive feedforward opposed by the PI correction, without an active boost or setpoint trajectory.
- Places the heating command and Thermal Twin step outputs side by side on desktop and stacks them on mobile.
- Shows a dotted Twin marker only for recent data and a model explicitly marked reliable. No forecast horizon is invented.
- Shows a numeric ETA only when its freshness and reliability checks pass. Otherwise, explains why no delay is available, including the maximum-heating scenario above the target.

## Included features

Live SmartPI diagnostics, historical charts, regulation inspection, model learning views and a local observatory. Temperature and preset changes require an explicit click on Apply for the linked thermostat. No automatic regulator tuning, calibration or schedule changes.

The observatory stores bounded local metadata in Home Assistant's native storage. Updating the component does not replace this storage. Back up your installation before updating.

## Validation

- TypeScript checks and reproducible frontend build.
- 73 Node tests and 46 Python tests with Home Assistant 2026.11.0, without skips.
- Browser interaction tests on synthetic fixtures at 1440, 390 and 320 px, including unavailable data, keyboard focus and preview/apply guards.
- Repository distribution validation and hassfest run in GitHub Actions; check the workflows linked to this release's commit.

These checks do not certify physical model accuracy or accessibility. No real thermostat commands were exercised in the acceptance tests.
