# SmartPI Dashboard 0.4.0

Clearer thermostat overview, dated chart values and descriptive observation tools.

## Changes

- Named/color-coded presets, separate selection marker, raw and filtered targets,
  and a proportional applied-command fill. Zero and unavailable values differ.
- Date/source/freshness near values; chart legends retain the selected publication
  on touch and pointer leave. Missing values at that instant remain explicit.
- Published model-monitoring stage replaces collection bars with a compact summary.
- Historical replay with keyboard navigation and an archived-only regulation diagram.
  Missing archived units are labelled as source units, never inherited from today.
- Room comparisons share axes within recorded-unit groups, using the last session
  hour. No performance ranking, energy inference or interpolation of missing data.
- Prospective raw-target response episodes show measured range, observed tolerance
  entry, directional overshoot, publication counts and exclusions. These are
  descriptive observations, not settling-time or controller-quality certifications.
- The Twin notebook places the frozen best-case ETA beside observed arrival.
  Incomparable scenarios receive no accuracy score; fixed-horizon forecast evaluation
  remains unavailable without a published horizon.

## Installation and data

Home Assistant **2026.11.0+**, SmartPI Diagnostics v2, administrator access.
Update the custom **Integration** repository in Marketplace, restart Home Assistant,
then reload the panel. The compiled bundle is included.

The existing private bounded observation store is preserved. The existing admin API
now exposes a closed projection of up to 1,200 recent points. New contextual metadata
is collected prospectively; old records are not retroactively completed. No new
thermostat service, schedule, tuning or calibration is added. Temperature/preset
changes still require explicit Apply on the linked thermostat.

## Verification

TypeScript, reproducible build, Node tests, Home Assistant Python tests and browser
fixtures cover desktop/mobile, light/dark, keyboard/touch, missing/stale/zero values,
unit/context changes, gaps, historical replay and model-monitoring transitions.
Check the workflows on the release commit for CI results. Tests on synthetic data
do not certify scientific accuracy or general accessibility.
